# Home loan essay

A small reactive essay about home loans in India, in the spirit of Bret Victor's explorable explanations.

**The idea:** most of the interest on a home loan is paid in the early years, and small, regular prepayments shorten a long loan dramatically. Readers drag numbers inside the text (loan amount, interest rate, tenure) and watch the EMI, the total interest and a principal vs interest chart update as they go.

Built with [Base UI](https://base-ui.com) (unstyled components) and [Motion](https://motion.dev). This essay is the first user of a small design system built on Base UI: its components move into that system once the essay ships.

Status: shaping. See [the product brief](docs/product/brief.md). Work is tracked in the [Linear project](https://linear.app/meatigo/project/home-loan-essay-2337af57bffa).
